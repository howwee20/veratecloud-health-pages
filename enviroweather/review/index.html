Meeting review report

Prepared for October 14, 2026, 11:00 AM Eastern. This is a public accessibility remediation preview with local station reports and scheduled source refreshes. It is not yet a certified or complete replacement for every legacy service.

What changed

  • Original branding, images, colors, page structure and desktop typography retained. Narrow-screen layout and keyboard focus are intentionally improved.
  • All 119 listed weather stations have local pages. Available source reports: 115 hourly, 115 daily and 119 maintenance logs, with 16,189 observation rows and 100 recent raw files.
  • Station selection, regional maps, report links, recent-date filtering and CSV downloads stay local.
  • 1032 captured agricultural and climate products are available locally. Historical publication dates and missing-value markers are preserved; a recent capture does not imply recent observations.
  • All 27 current climate maps have local enlarged views, matching dates and legends, and regional text samples with a CSV download.
  • Headings, labels, table headers, skip links, visible focus, usable control targets, and missing-data announcements improve access.

Freshness and failure handling

GitHub Actions requests read-only updates hourly, subject to GitHub scheduling and publisher availability. Each host is limited to fewer than one request per second. A successful build publishes the results. The displayed saved time identifies capture time; dates inside reports identify observations. Historical content is cached for up to 30 days.

Weather parsing and map date/legend validation run before publication. Unreadable reports retain their last validated copy when available. Failed builds retain the existing deployment. This is periodic refresh, not a streaming feed.

Technology and ownership

Astro generates static HTML and CSS. TypeScript/JavaScript handles station selection and local report filtering. Python captures and validates source data and climate-map dates/legends. GitHub Actions YAML runs the refresh and GitHub Pages hosts the public site. Original server-side source code and databases were not supplied; the old ASP query engine is not reproduced.

Checks and evidence

Download the verification report. Automated checks cover source-value preservation, local links, page loading, keyboard focus, responsive layout, text spacing and detectable accessibility issues. Representative routes are checked in Chromium, Firefox and WebKit.

What remains before a complete production replacement

  1. A supported data service or export for arbitrary historical dates, five-minute observations, growing-degree-day calculations and raw archives beyond the recent three-hour files.
  2. Complete historical archive migration. Uncopied archive items show a local availability notice rather than redirecting visitors to the old sites.
  3. Publisher access to two agricultural temperature graphics that currently return HTTP 403. Daily station maximum/minimum observations are offered as related data, not as identical map replacements.
  4. Content-specific alternatives and manual review for imported historical charts, PDFs, Office files and fixed-width reports. Regional samples do not reproduce every climate-map grid value.
  5. Full-scope assistive-technology testing and MSU’s institutional review, followed by operational acceptance by the site owners.

Four retired stations (BAT, GDE, PTR and SGA) do not supply eight recent hourly/daily reports. The local pages state this; observations are not fabricated. NOAA, Wisconsin and supporting-organization links remain external services.

Accessibility status

The target is WCAG 2.2 AA under MSU’s technical guidelines. This release has not received a new institutional Silktide score. Automated results do not certify ADA compliance; MSU explains that manual evaluation is still required.

The October 14 meeting is a project review, not a legal certification deadline. This report does not claim legal approval, perfect visual identity at every size, or complete functional parity with the original backend.
