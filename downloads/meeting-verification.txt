VISUAL AND ACCESSIBILITY CHANGES
Original branding, images, colors and desktop structure retained. Changes include
keyboard station selection, visible focus, skip links, labelled controls, usable
control targets, table headers, missing-value text, mobile reflow, contained
scrolling for wide data tables, and long-text wrapping. These changes intentionally
prevent an exact pixel match at every viewport or accessibility setting.

WHAT THESE CHECKS DO NOT ESTABLISH
Automated checks cannot verify every meaningful image description, complex chart
or document equivalent, screen-reader interpretation, or legal obligation. The
expanded release has not received a new institutional MSU Silktide score. The
user confirmed VoiceOver was working earlier; that is not a spoken screen-reader
review of every newly added page. Imported historical charts, PDFs, Office files
and fixed-width source reports still need content-specific manual review.

UPDATES AND RELIABILITY
A GitHub Actions workflow is scheduled hourly at minute 17. Scheduling, source
availability and validation can delay publication. It uses maintainer-authorized,
read-only requests with at least 1.1 seconds between request starts per source
host. Current report caches expire after 30 minutes; historical reference content
is cached for up to 30 days. Failed parsing retains a prior verified report when
available. Maps are published only after image/date/legend validation. Failed
builds leave the previous public deployment in place. This is not streaming data.
Saved time means capture time. Dates inside reports remain the observation or
publication dates. Some original NWS products are discontinued and dated 2025;
those are labelled as archived. Missing observations are not fabricated.

REMAINING WORK FOR A FULL PRODUCTION REPLACEMENT
1. Supported MSU data access/export for arbitrary historical dates, five-minute
   observations, growing-degree-day calculations and additional raw archives.
   The original ASP database query engine was not supplied or reproduced.
2. Complete the remaining historical archive migration. Current local notices
   deliberately prevent a surprise redirect to an old host.
3. Restore publisher access to two agricultural temperature JPEGs returning 403.
   Local daily station maxima/minima are related data, not identical map copies.
4. Supply/review complete alternatives for historical graphics and documents and
   underlying climate grids. Regional raster samples are approximate, not every
   original grid value.
5. Complete manual assistive-technology review, institutional MSU evaluation and
   owner acceptance of operation, refresh failure handling and hosting.
Four retired stations (BAT, GDE, PTR, SGA) lack eight hourly/daily reports at the
source. Their local pages disclose this rather than inventing observations.

LANGUAGES AND HOSTING
Astro with TypeScript/JavaScript generates HTML and CSS. JavaScript handles local
station selection and report filtering. Python captures, parses and validates
source data and map images. YAML defines GitHub Actions. GitHub Pages serves the
public site. EMR and the title-only showcase tiles are preserved separately.
